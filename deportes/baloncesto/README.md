# 🏀 Calendarios de baloncesto

Calendarios independientes para equipos de baloncesto. Cada club mantiene su
propio estado y su propio workflow.

- [Movistar Estudiantes](estudiantes.ics): Primera FEB, Copa España y playoffs (FEB).
  URL: `https://raw.githubusercontent.com/davidveju/calendarios/main/deportes/baloncesto/estudiantes.ics`
- [Real Madrid Baloncesto](madrid.ics): Liga Endesa (ACB oficial, con resultados) + EuroLeague (API oficial de resultados).
  URL: `https://raw.githubusercontent.com/davidveju/calendarios/main/deportes/baloncesto/madrid.ics`

## Publicación, estado y código

Los `.ics` públicos quedan en `deportes/baloncesto/`. Estado y código aparte:

```text
estado/deportes/baloncesto/estudiantes/
scripts/calendarios/deportes/baloncesto/estudiantes/
estado/deportes/baloncesto/madrid/
scripts/calendarios/deportes/baloncesto/madrid/
```

La Copa del Rey se publicará cuando la ACB publique cruces/pairings (febrero).
Los resultados de EuroLeague/ACB sí se actualizan ahora automáticamente.
