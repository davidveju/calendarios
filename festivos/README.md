# 🎉 Festivos de Madrid

Calendario de festivos de la Comunidad/Provincia de Madrid, con las fiestas
locales de la ciudad (San Isidro y Almudena) incluidas.

- Fichero: [madrid.ics](madrid.ics)
- Actualización: el 1 de cada mes (por traslado oficial y cálculo de años futuros).
- Código y estado: `scripts/calendarios/festivos/madrid/` y `estado/festivos/madrid/`.
